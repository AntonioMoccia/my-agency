# Categorie di servizi per tipologia

Elenco delle categorie da coprire e delle opzioni comuni. **Senza prezzi**: i prezzi si verificano online al momento, nella skill `costi`.

## Sempre, per qualsiasi tipologia
| Categoria | Opzioni comuni |
|---|---|
| Dominio | Registrar generalisti, registrar italiani, registrar del provider di hosting |
| Hosting / deploy | Piattaforme di deploy per framework JavaScript, hosting gestito, VPS |
| Certificato HTTPS | Incluso nelle piattaforme di deploy, oppure Let's Encrypt |
| Email del dominio | Suite da ufficio in cloud, provider email dedicati, email incluse nell'hosting |
| Email transazionali | Servizi di invio trasferibile via API o SMTP |
| Analytics | Analytics gratuiti dei grandi provider, analytics rispettosi della privacy, analytics della piattaforma di hosting |
| Cookie e consenso | Piattaforme di consenso a pagamento, soluzioni self-hosted, banner propri |
| Backup | Incluso nel repository Git, snapshot del database, backup dei media |
| Monitoraggio errori | Servizi di error tracking, log della piattaforma di hosting |

## Vetrina e portfolio
| Categoria | Opzioni comuni |
|---|---|
| CMS | Nessuno (contenuti nel codice), CMS headless in cloud, CMS integrato nell'app, CMS basato su file Git |
| Form di contatto | Servizio di form gestito, endpoint proprio + email transazionali |
| Media | CDN immagini incluso nell'hosting, servizi di ottimizzazione immagini, hosting video |
| Prenotazioni (opzionale) | Servizi di booking in cloud, calendario integrato |

## Ecommerce
| Categoria | Opzioni comuni |
|---|---|
| Piattaforma | Piattaforma ecommerce in cloud (tema o headless), ecommerce self-hosted, checkout a link di pagamento |
| Pagamenti | Gateway internazionali, gateway bancari italiani, pagamenti differiti e rateali |
| Spedizioni | Corrieri con API, aggregatori di spedizioni, calcolo tariffe |
| Fatturazione elettronica | Servizi italiani di fatturazione elettronica e invio allo SdI |
| Gestione magazzino | Incluso nella piattaforma, gestionale esterno collegato |
| Email marketing | Piattaforme di newsletter con automazioni |
| Ricerca prodotti | Ricerca inclusa, motori di ricerca dedicati |
| Recensioni | Piattaforme di recensioni verificate |

## Blog ed editoriale
| Categoria | Opzioni comuni |
|---|---|
| CMS | CMS headless in cloud, CMS basato su file Markdown nel repository, CMS tradizionale |
| Newsletter | Piattaforme di newsletter, piattaforme di publishing con abbonamento |
| Commenti | Servizi di commenti gestiti, commenti basati sulle issue del repository |
| Ricerca interna | Ricerca statica lato client, motori di ricerca dedicati |

## Web app e software gestionale
| Categoria | Opzioni comuni |
|---|---|
| Database | Postgres gestito, database serverless, database incluso nella piattaforma di deploy |
| Autenticazione | Servizi di auth gestiti, librerie di auth self-hosted, SSO aziendale |
| File e media | Storage a oggetti compatibile S3, storage della piattaforma di deploy |
| Code e job | Code gestite, cron della piattaforma, worker dedicati |
| Pagamenti e abbonamenti | Gateway con gestione abbonamenti, piattaforme merchant of record |
| Notifiche | Email transazionali, SMS, push |
| Supporto | Servizi di chat e ticketing |
| Ambienti | Anteprime per branch, ambiente di staging separato, variabili per ambiente |

## App mobile
| Categoria | Opzioni comuni |
|---|---|
| Account sviluppatore | Store Apple (annuale), store Google (una tantum) |
| Build e distribuzione | Servizi di build in cloud, pipeline CI proprie |
| Push | Servizi push dei grandi provider, servizi push dedicati |
| Crash e analytics | SDK di crash reporting, analytics mobile |
| Aggiornamenti over-the-air | Servizi di update OTA, se il framework lo consente |

## Voci che spesso si dimenticano
- Rinnovo del dominio (il primo anno è spesso scontato: contare il **rinnovo**).
- Font con licenza web, se non si usano font open source.
- Immagini da banca dati, se servono foto professionali.
- Traduzioni, se il sito è multilingua.
- Costo del superamento dei limiti dei piani: banda, build, righe del database, email inviate.
- Manutenzione e aggiornamenti dopo il lancio, se prevista nel contratto.
