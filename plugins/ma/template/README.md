# Progetto sito / app

| Cartella / file | Contenuto |
|---|---|
| `contesto/` | Stato, discovery, stile, decisioni e costi del progetto |
| `onboarding.md` | Risposte alle 4 domande: tipologia, struttura, tecnologie, stile |
| `istruzioni/` | Come configurare i servizi esterni |
| `riferimenti/` | Logo e brand esistenti, screenshot dei riferimenti di stile |
| `resources/` | Tabella `resources.md` + materiale (riferimenti, brand, immagini, testi, video) |
| `design/` | Stile, mockup e design approvati; le proposte in `design/proposte/` |
| `contratto/` | Bozza di contratto e allegati |
| `sito/` | Cartella di lavoro: il codice |

Flusso: `/ma:progetto` → inserisci le risorse o `/ma:design` → approvi il design → sviluppo in `sito/`.
