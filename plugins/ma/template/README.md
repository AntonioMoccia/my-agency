# Website / app project

| Folder / file | Contents |
|---|---|
| `context/` | State, discovery, style, decisions, costs and visual inspiration |
| `onboarding.md` | Answers to the setup questions: typology, structure, technologies, style |
| `instructions/` | How to configure the external services |
| `references/` | Existing logo and brand, screenshots of the style references |
| `resources/` | The `resources.md` table + the material (references, brand, images, texts, video) |
| `design/` | Style, mockups and approved design; the proposals in `design/proposals/` |
| `contract/` | Contract draft and attachments |
| `site/` | Working folder: the code |

Flow: `/ma:project` → add the resources or run `/ma:design` → approve the design →
development in `site/`.

Files that appear as the project progresses: `context/state.md`, `discovery.md`,
`style.md`, `inspiration.md`, `decisions.md`, `costs.md`, `questionnaire.md`, and in
refactoring mode `source.md`, `audit.md`, `specs.md`, `plan.md`.
