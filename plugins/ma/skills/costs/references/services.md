# Service categories per typology

A list of the categories to cover and the common options. **No prices**: prices are
checked online at the time, inside the `costs` skill.

## Always, for any typology
| Category | Common options |
|---|---|
| Domain | Generalist registrars, local registrars, the hosting provider's registrar |
| Hosting / deploy | Deploy platforms for JavaScript frameworks, managed hosting, VPS |
| HTTPS certificate | Included in the deploy platforms, or Let's Encrypt |
| Domain email | Cloud office suites, dedicated email providers, mailboxes included with hosting |
| Transactional email | Sending services, transferable, via API or SMTP |
| Analytics | Free analytics from the large providers, privacy-respecting analytics, the hosting platform's own |
| Cookies and consent | Paid consent platforms, self-hosted solutions, your own banner |
| Backup | Included in the Git repository, database snapshots, media backups |
| Error monitoring | Error tracking services, the hosting platform's logs |

## Brochure site and portfolio
| Category | Common options |
|---|---|
| CMS | None (content in the code), cloud headless CMS, CMS embedded in the app, Git-file-based CMS |
| Contact form | Managed form service, own endpoint + transactional email |
| Media | Image CDN included with hosting, image optimisation services, video hosting |
| Bookings (optional) | Cloud booking services, embedded calendar |

## Ecommerce
| Category | Common options |
|---|---|
| Platform | Cloud ecommerce platform (themed or headless), self-hosted ecommerce, payment-link checkout |
| Payments | International gateways, local bank gateways, deferred and instalment payments |
| Shipping | Couriers with APIs, shipping aggregators, rate calculation |
| Electronic invoicing | Local e-invoicing services and submission to the tax authority |
| Stock management | Included in the platform, external ERP connected |
| Email marketing | Newsletter platforms with automations |
| Product search | Built-in search, dedicated search engines |
| Reviews | Verified review platforms |

## Blog and editorial
| Category | Common options |
|---|---|
| CMS | Cloud headless CMS, Markdown-file CMS in the repository, traditional CMS |
| Newsletter | Newsletter platforms, subscription publishing platforms |
| Comments | Managed comment services, comments backed by repository issues |
| Internal search | Static client-side search, dedicated search engines |

## Web app and business software
| Category | Common options |
|---|---|
| Database | Managed Postgres, serverless databases, database included with the deploy platform |
| Authentication | Managed auth services, self-hosted auth libraries, corporate SSO |
| Files and media | S3-compatible object storage, the deploy platform's storage |
| Queues and jobs | Managed queues, the platform's cron, dedicated workers |
| Payments and subscriptions | Gateways with subscription management, merchant-of-record platforms |
| Notifications | Transactional email, SMS, push |
| Support | Chat and ticketing services |
| Environments | Per-branch previews, a separate staging environment, per-environment variables |

## Mobile app
| Category | Common options |
|---|---|
| Developer account | Apple store (annual), Google store (one-off) |
| Build and distribution | Cloud build services, own CI pipelines |
| Push | Push services from the large providers, dedicated push services |
| Crash and analytics | Crash reporting SDKs, mobile analytics |
| Over-the-air updates | OTA update services, where the framework allows it |

## Items that often get forgotten
- Domain renewal (the first year is often discounted: count the **renewal**).
- Web-licensed fonts, if open source fonts are not used.
- Stock imagery, if professional photos are needed.
- Translations, if the site is multi-language.
- The cost of exceeding plan limits: bandwidth, builds, database rows, emails sent.
- Maintenance and updates after launch, if the contract includes them.
