# Web development contract template

A template to fill in. Anything that cannot be derived from the project context stays as
`[TO COMPLETE: …]`.

This template is written in English because the plugin's files are. The **delivered
draft is written in the project language** from `context/state.md` — translate the
headings and the clauses, keep the structure. The clauses assume an **Italian**
engagement (VAT number, e-invoicing, GDPR, Italian jurisdiction): adapt them if the
project is governed by another law, and say so in one line.

---

> **Draft to be reviewed by a lawyer or an accountant. It requires an issuing entity
> with a VAT number or a registered company.**
